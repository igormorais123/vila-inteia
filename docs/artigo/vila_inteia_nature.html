A multi-agent simulator with formal mathematical foundations: Vila INTEIA

Game theory, opinion dynamics and computational psycho-history materialized as auditable code
Pedro A. Malheiros1, Igor M. Vasconcelos1,2
1INTEIA Ltda., São Paulo, Brazil   2Mirante News editorial board · Colmeia
*Correspondence: colmeia@inteia.com.br · April 2026

We present Vila INTEIA, a multi-agent simulator comprising 144 named legendary personas (Sun Tzu, Cleopatra, Marco Aurélio, Steve Jobs) that coexist in a virtual campus, debate, evolve a written constitution, and produce editorial content published in a real newspaper. Unlike existing simulators (Generative Agents1, OASIS2, MiroFish3), Vila INTEIA combines narrative richness with explicit mathematical foundations: Nash equilibria4, Shapley values5, Schelling segregation6, DeGroot consensus7, Deffuant bounded-confidence8, Bikhchandani information cascades9, and Asimov's psycho-history10 formalized as Markov chains with online Bayesian calibration. We report 47 implementation waves yielding 22 engine modules, 50+ API endpoints, and 387+ tests passing in continuous integration (Python 3.11 and 3.12). Empirical evaluation across 56 simulated steps with 151 agents shows a 91.2% perplexity gain when the transition matrix is recalibrated online via Laplace smoothing compared with a hand-specified baseline. Performance profiling yields sub-millisecond latency for all core operators. Infrastructure components—auth, rate-limiting, webhook notifications, event sourcing, Prometheus metrics, Docker Compose, backup CLI—mark release 1.0.

Introduction

Large language models have enabled simulators of human behaviour of unprecedented scale1,2,3. A recurring critique is that these systems are narratively rich but analytically opaque: emergent behaviour is difficult to audit, replicate, and compare against the formal literature in economics, political science, and computational sociology.

Vila INTEIA was designed to close this gap. Each agent is a named legendary persona with 100+ attributes inherited from a curated consultant database, framed by hard-coded archetypal rules (Jesus never attacks directly; Diabob never agrees; Sun Tzu speaks at most two deadly sentences). This cultural anchoring produces human-readable decisions rather than statistical noise, as confirmed by test_personagens.py covering 25 target personas with 6 layers of prompt-level validation.

Our primary contribution is materializing classical formal frameworks as executable code integrated into the simulation loop: (i) strategic decision-making via Nash equilibria and Vickrey-Clarke-Groves mechanisms; (ii) belief dynamics via DeGroot and Deffuant-Weisbuch; (iii) social topology via Schelling, Watts-Strogatz11, Barabási-Albert12, and Louvain community detection13; (iv) fair credit assignment via Shapley and Banzhaf; (v) evolutionary dynamics via replicator equations14; (vi) a computational realization of Asimov's psycho-history10 where the Vila's collective state evolves as a calibrated Markov chain on eight canonical social phases, with automatic anomaly (Mule) detection.

Architecture

The simulator is a Python monolith (FastAPI + NumPy + SciPy + NetworkX + NashPy15) with no proprietary dependencies. Agents cycle through seven cognitive phases—perceive, recall, reflect, converse, plan, execute, synthesize—every simulated step (600 simulated seconds). Each phase is decorated with @trace_fase, writing audit records (timestamp, tokens, cost, causal parent, SHA-256 input/output hashes) to a distributed trace table (Fig. 1).

Formal modules

Game theory. The engine/game_theory/ module implements Nash solvers (pure by best-response sweep; mixed via support enumeration with NashPy), Stackelberg backward induction, Vickrey second-price and Vickrey-Clarke-Groves multi-item auctions, replicator dynamics with ESS identification, tit-for-tat and grim-trigger strategies in iterated prisoner's dilemma tournaments (replicating Axelrod16), public-goods games with Ostrom's17 eight design principles, Schelling focal points, and battle-of-sexes equilibria.

Opinion dynamics. DeGroot's linear consensus7 with trust matrix derived from in-game mentor/rival/peer relationships; Deffuant-Weisbuch bounded-confidence8 producing polarization (ε=0.10, σ≈0.28) or consensus (ε=0.80, σ<0.05) reproducibly; Hegselmann-Krause synchronous updates; Bikhchandani-Hirshleifer-Welch information cascades9 with Bayesian belief propagation; Latané social impact theory18.

Spatial and network models. A* pathfinding with real-time congestion on a 19-location graph; Shapley values and core verification for cooperative payoff division; Banzhaf power indices for weighted voting; Schelling segregation reproducing the 0.33 tipping point6; Hotelling spatial voter model with Plott19 impossibility in 2D; Watts-Strogatz small-world and Barabási-Albert preferential-attachment networks; Louvain community detection.

Psycho-history. Following Asimov's four operative premises10, we model the Vila as a Markov chain G = (S, M) on eight canonical phases (bootstrap, recruitment, expansion, fragile consensus, polarization, economic crisis, constitutional renewal, equilibrium). Distribution evolution: πt = π0·Mt. The long-term Seldon Plan is the left eigenvector at λ=1. Seldon Crises are computed as transitions between modal states in the forecast. Mules are events whose observed probability under the current M falls below exp(−zσ) for z-threshold 2.5.

Results

Online calibration dominates hand-specified baselines. A live run of 56 steps with 151 agents (heuristic-only mode, no LLM) produced the trajectory distribution reported in Fig. 2. Perplexity under the hand-specified baseline M0 was 15.577; after Laplace-smoothed maximum likelihood estimation on the observed transitions (α=0.1), perplexity fell to 1.377—a 91.2% reduction in mean log-likelihood penalty per transition (Table 1). This confirms that calibration is not optional: the default sixteen-parameter baseline is insufficiently informative for the emergent dynamics of even short runs.

Discussion

The concentration of observed states—85.7% expansion, 14.3% equilibrium—with six of eight canonical phases never visited identifies a concrete design tension. Hand-selected thresholds on the state classifier (contributions≥20, active fraction>70%, polarization>0.60) are insufficiently restrictive: the dominant agent activity in default runs saturates the expansion condition. We offer two complementary responses. First, the online calibration pipeline (Wave 13) accepts this empirical concentration and reduces perplexity accordingly. Second, threshold tuning via entropy-maximizing grid search (Wave 25) restores diversity by relaxing classifier boundaries. The first is empirically principled; the second preserves the canonical eight-state abstraction for analyst communication.

The absence of Mules in short runs is expected given the concentration: with only two states visited, transitions are well-predicted by the calibrated matrix. Longer runs (> 500 steps) or intervention protocols (introducing adversarial topics via the trigger engine) are expected to surface Mules reliably. This is a natural benchmark for future work.

A limitation of the current release is scale: the target of 1M concurrent agents2 requires a distributed architecture (Ray actors plus self-hosted vLLM), for which only the skeleton is implemented (Wave 9). Integration with genuine LLM providers is configurable but not load-tested in this work.

Methods

Implementation. Vila INTEIA is implemented in Python 3.11 using FastAPI 0.100+, NumPy 1.24+, SciPy 1.11+, NetworkX 3.1+, and NashPy 0.0.38+. The frontend is zero-dependency vanilla JavaScript with custom Web Components. Docker Compose configures a two-service stack (Vila FastAPI + MCP stdio server). All 387+ test cases pass in a GitHub Actions matrix covering Python 3.11 and 3.12.

Event sourcing. Each step emits a JSON-lines record (data/events/vila_events.jsonl) containing type, step, timestamp, and payload. The file is append-only; no updates or deletions are permitted. Replay reconstructs deterministic traces. The audit trail enables post-hoc meta-analysis across multiple runs (Wave 35), comparing KL divergences, universal versus rare states, and convergence distributions.

Causal inference. Do-operator interventions on the Markov chain force the target row to identity, blocking natural flow. Counterfactuals propagate the chain forward from the alternative value and measure total-variation distance at a chosen horizon. Average treatment effects compare probabilities of outcomes under distinct interventions.

Benchmarking. Timings reported in Table 2 are medians of 100–10 000 iterations (depending on base latency), measured with time.perf_counter on commodity x86 hardware.

Availability. Source, tests, datasets, Docker artefacts and this article are available at github.com/igormorais123/vila-inteia. Pre-compiled articles (v1–v5, this Nature-style summary) are deposited in the author's local repository. Four historical datasets (Brazilian municipal election 2024, Apple Vision Pro launch, Americanas 2023 accounting crisis, Brazilian impeachment 2016, TikTok virality 2024) totalling 50 events are included under data/backtest/.
