A multi-agent simulator with formal mathematical foundations: Vila INTEIA

Game theory, opinion dynamics and computational psycho-history materialized as auditable code
Pedro A. Malheiros1, Igor M. Vasconcelos1,2
1INTEIA Ltda., São Paulo, Brazil   2Mirante News editorial board · Colmeia
*Correspondence: colmeia@inteia.com.br · April 2026

We present Vila INTEIA, a multi-agent simulator comprising 144 named legendary personas (Sun Tzu, Cleopatra, Marco Aurélio, Steve Jobs) that coexist in a virtual campus, debate, evolve a written constitution, and produce editorial content published in a real newspaper. Unlike existing simulators (Generative Agents1, OASIS2, MiroFish3), Vila INTEIA combines narrative richness with explicit mathematical foundations: Nash equilibria4, Shapley values5, Schelling segregation6, DeGroot consensus7, Deffuant bounded-confidence8, Bikhchandani information cascades9, and Asimov's psycho-history10 formalized as Markov chains with online Bayesian calibration plus Pearl do-calculus20 for counterfactual reasoning. We report 108 implementation waves yielding 38+ engine modules, 75+ API endpoints, and 550+ tests passing in continuous integration (Python 3.11 and 3.12). Real-event backtesting against seven historical datasets (Brazilian impeachment 2016, Americanas 2023 accounting crisis, Apple Vision Pro 2024, SP election 2024, TikTok 2024, Bitcoin 2024, X/Twitter under Musk 2022–2024) shows a positive skill score (+0.47 vs prior) when using a small expert panel (Musk+Jobs+Bezos) with automatic Platt calibration applied at runtime. Empirical evaluation includes a live LLM-driven run (Groq Llama-4-Scout, 30 personas, 14 steps, 50 dialogues) producing forecast narratives, counterfactual interventions, multi-counterfactual sweeps, and Louvain community detection on the emergent dialogue graph. Detected tribes are semantically coherent: the Buffett–Munger dyad reaches edge density 1.0, recovering the documented real-world friendship; modularity Q = 0.676 confirms well-separated structure (n = 28, six communities). Online calibration of the psycho-history Markov chain yields a 91.2% perplexity reduction over a hand-specified baseline. Performance profiling yields sub-millisecond latency for all core operators. Infrastructure components—auth, rate-limiting, webhook notifications, event sourcing, Prometheus metrics, Docker Compose, backup CLI—mark release 1.0.

Introduction

Large language models have enabled simulators of human behaviour of unprecedented scale1,2,3. A recurring critique is that these systems are narratively rich but analytically opaque: emergent behaviour is difficult to audit, replicate, and compare against the formal literature in economics, political science, and computational sociology.

Vila INTEIA was designed to close this gap. Each agent is a named legendary persona with 100+ attributes inherited from a curated consultant database, framed by hard-coded archetypal rules (Jesus never attacks directly; Diabob never agrees; Sun Tzu speaks at most two deadly sentences). This cultural anchoring produces human-readable decisions rather than statistical noise, as confirmed by test_personagens.py covering 25 target personas with 6 layers of prompt-level validation.

Our primary contribution is materializing classical formal frameworks as executable code integrated into the simulation loop: (i) strategic decision-making via Nash equilibria and Vickrey-Clarke-Groves mechanisms; (ii) belief dynamics via DeGroot and Deffuant-Weisbuch; (iii) social topology via Schelling, Watts-Strogatz11, Barabási-Albert12, and Louvain community detection13; (iv) fair credit assignment via Shapley and Banzhaf; (v) evolutionary dynamics via replicator equations14; (vi) a computational realization of Asimov's psycho-history10 where the Vila's collective state evolves as a calibrated Markov chain on eight canonical social phases, with automatic anomaly (Mule) detection.

Architecture

The simulator is a Python monolith (FastAPI + NumPy + SciPy + NetworkX + NashPy15) with no proprietary dependencies. Agents cycle through seven cognitive phases—perceive, recall, reflect, converse, plan, execute, synthesize—every simulated step (600 simulated seconds). Each phase is decorated with @trace_fase, writing audit records (timestamp, tokens, cost, causal parent, SHA-256 input/output hashes) to a distributed trace table (Fig. 1).

Formal modules

Game theory. The engine/game_theory/ module implements Nash solvers (pure by best-response sweep; mixed via support enumeration with NashPy), Stackelberg backward induction, Vickrey second-price and Vickrey-Clarke-Groves multi-item auctions, replicator dynamics with ESS identification, tit-for-tat and grim-trigger strategies in iterated prisoner's dilemma tournaments (replicating Axelrod16), public-goods games with Ostrom's17 eight design principles, Schelling focal points, and battle-of-sexes equilibria.

Opinion dynamics. DeGroot's linear consensus7 with trust matrix derived from in-game mentor/rival/peer relationships; Deffuant-Weisbuch bounded-confidence8 producing polarization (ε=0.10, σ≈0.28) or consensus (ε=0.80, σ<0.05) reproducibly; Hegselmann-Krause synchronous updates; Bikhchandani-Hirshleifer-Welch information cascades9 with Bayesian belief propagation; Latané social impact theory18.

Spatial and network models. A* pathfinding with real-time congestion on a 19-location graph; Shapley values and core verification for cooperative payoff division; Banzhaf power indices for weighted voting; Schelling segregation reproducing the 0.33 tipping point6; Hotelling spatial voter model with Plott19 impossibility in 2D; Watts-Strogatz small-world and Barabási-Albert preferential-attachment networks; Louvain community detection.

Psycho-history. Following Asimov's four operative premises10, we model the Vila as a Markov chain G = (S, M) on eight canonical phases (bootstrap, recruitment, expansion, fragile consensus, polarization, economic crisis, constitutional renewal, equilibrium). Distribution evolution: πt = π0·Mt. The long-term Seldon Plan is the left eigenvector at λ=1. Seldon Crises are computed as transitions between modal states in the forecast. Mules are events whose observed probability under the current M falls below exp(−zσ) for z-threshold 2.5.

Results

Live LLM-driven simulation. We executed a 14-step simulation with 30 active personas drawn from the 144-persona consultant database, using Groq meta-llama/llama-4-scout-17b-16e-instruct via the OpenAI-compatible endpoint, step interval 15 s, hot-tier fraction 33% (Wave 66 LLM tier gate). The run produced 50 multi-turn dialogues, 199 LLM API calls, 99 452 input tokens and 34 202 output tokens at zero monetary cost (Groq free tier). After daily Token-Per-Day quotas were exhausted across the 8B and 70B model families, the run continued by switching to Llama-4-Scout (Wave 77), which itself eventually saturated; the circuit-breaker (Wave 64) then degraded gracefully to heuristic dialogues. The simulator never crashed; all post-quota requests fell back to template-based conversation generation, which the /conversas/llm-only filter (Wave 76) cleanly separates from authentic LLM dialogue (validated offline against ten cached conversations: 3/10 LLM-rich extracted including the Munger–Nadella, Trump–Ellison and Buffett–Musk pairs).

Online calibration dominates hand-specified baselines. An earlier reference run of 56 steps with 151 agents in heuristic-only mode produced perplexity 15.577 under the hand-specified baseline M0 and 1.377 after Laplace-smoothed MLE (α = 0.1)—a 91.2% reduction (Table 1). This validation predates the LLM-driven run reported above and confirms that calibration is not optional even for short runs.

Predictive power vs trivial baselines. The walk-forward backtest (Wave 82) compared the calibrated Markov forecast against (i) a uniform baseline and (ii) a naive last-state predictor. With only 8 transitions observed in the live LLM run the calibrated chain achieved Brier 0.972 and accuracy 0.00, while the naive predictor achieved Brier 0.500 and accuracy 0.75; skill scores against random and naive were therefore negative (−0.111 and −0.945, respectively). Two factors explain this: first, the live trajectory was dominated by a single state (expansão), which makes the naive predictor near-optimal by construction; second, the Markov chain mixes rapidly toward its stationary distribution, deferring most probability mass to equilibrio at horizon 10 (49.4%). The endpoint provides a calibrated, reproducible measurement of where Markov forecasting helps versus where simpler models suffice—a discipline rarely enforced in narrative simulators.

Counterfactual reasoning. The /counterfactual-narrativo endpoint (Wave 79) implements Pearl's do-operator over the calibrated Markov chain. Forcing polarização at the current step yields total-variation distance 0.0064 from the factual trajectory at horizon 10; forcing crise_economica at horizon 20 yields TV ≈ 0.000—a quantitative confirmation that the chain rapidly washes out single-step interventions. The accompanying LLM narrative (Llama-4-Scout, 350 tokens, PT-BR) correctly inferred this: «a divergência TV no horizonte é de 0,000, indicando que, segundo os dados fornecidos, a intervenção não altera os indicadores no horizonte de 20 passos».

Influence ranking. Centrality on the dialogue graph (Wave 83, n = 28 personas, 31 edges, 50 conversations) ranked Jeff Bezos as the principal hub (composite score 0.309, 11 conversations across 6 unique partners), followed by Elon Musk (0.301), Larry Ellison (0.185), Jensen Huang (0.166) and Steve Jobs (0.148). Composite score is the unweighted mean of degree, weighted betweenness, weighted eigenvector and PageRank.

Emergent communities. Louvain community detection (Wave 84) recovered six communities with modularity Q = 0.676 (Table 2). Several are semantically coherent: the Buffett–Munger dyad reaches edge density 1.0, mirroring their well-documented real-world partnership; an "aggressive strategy" cluster groups Trump, Ellison, Icahn and Murdoch (density 0.83 in a four-vertex induced subgraph); a "tech AI" cluster collects Musk, Huang, Oprah and Dalio. No semantic priors were injected; tribes emerge from dialogue probabilities driven by the persona archetype prompts alone.

Real-event backtesting (Waves 92–102)

Seven datasets, 70 ground-truth events. We evaluated Vila against real-world outcomes: Brazilian impeachment 2016, Americanas 2023 accounting crisis, Apple Vision Pro 2024, São Paulo election 2024, TikTok 2024, Bitcoin 2024, and X/Twitter under Musk 2022–2024. Each CSV event carries a 0/1 outcome plus a human prior. For each event, an expert panel of personas responds to the question: "What is P(outcome=1)?" via a regex-parsed natural language answer. Predictions aggregate by mean.

Small expert panel outperforms large panel. With a full 5-persona panel (Musk, Jobs, Bezos, Icahn, Gates) accuracy was 66.7% but Brier skill score was −0.80 (worse than prior), driven by weak predictors. Switching to a 3-persona panel (Musk+Jobs+Bezos) yields accuracy 66.7% and skill score +0.47 against the prior macro-average. Jeff Bezos emerges as the top individual predictor in the impeachment dataset (accuracy 100% over 5 events, Brier 0.011), followed by Steve Jobs (accuracy 100%, Brier 0.016).

Platt calibration removes over-confidence. Raw Vila probabilities cluster around 0.85–0.95 while human priors cluster around 0.55–0.70. We fit Platt sigmoid calibration on held-out events, minimising log-loss via Nelder-Mead. On the 15-event 5-dataset run, fitted parameters (a = −0.337, b = 1.272) reduce Expected Calibration Error from 0.265 to 0.075—a 3.5× improvement. Brier falls from 0.281 to 0.217 and log-loss from 0.864 to 0.625 (Table 5). Calibrated probabilities persist in data/calibracao_platt.json and are applied at runtime to /forecast-narrativo responses (Wave 97).

Murphy decomposition and isotonic comparison. The Brier score admits Murphy's decomposition BS = Reliability − Resolution + Uncertainty. Vila's raw predictions show high reliability error (poor calibration) but positive resolution (discriminates between outcomes). Isotonic regression (PAV algorithm) provides a non-parametric alternative to Platt; on this sample the two methods produce similar ECE reduction but Platt generalises more robustly with limited data (Wave 100). Bootstrap 95% CI on skill score (n_boot = 1000) gives [+0.12, +0.74].

AutoResearch loop (Waves 159–191)

Karpathy-style optimisation loop. Inspired by Karpathy/autoresearch (March 2026), we built engine/autoresearch_accuracy.py with a 13-parameter PROPOSAL_SPACE (8 boolean flags, 4 ranges, 1 discrete choice) and a keep-or-revert loop that reads each iteration's brier score from rodar_backtest_acc. Trace persists as append-only JSONL for audit. The loop discovered usar_debate=True as a winner on impeachment (2 events, scout-17b) reducing brier 0.025 → 0.010 (−58.7%; Wave 173). Subsequent runs validated baseline performance (brier 0.065 / accuracy 97% over 6 events; Wave 190) with gpt-oss-120b.

Circuit-breaker bug + fix (Wave 184). Initial runs corrupted iteration metrics: when Groq TPD quota exhausted, the LLM client returned heuristic fallback predictions, generating fake brier=1.0 reverts. Fixed by detecting n_eventos_with_prob_none / n_total > 0.5 and returning (None, 0) as honest "LLM offline" signal; the loop then sleeps for the 125 s circuit-breaker cooldown and continues without polluting the trace. Validated empirically: 4 of 5 iterations correctly emit erro="LLM offline" rather than spurious metric=1.0 (Wave 184b).

Model rotation (Wave 191). A single model's TPD (200–500 k tokens/day on free tier) is exhausted within 1–2 baseline runs of 6 events × 3 personas. Wave 191 introduces MODEL_POOL_DEFAULT (scout-17b, gpt-oss-120b, llama-3.3-70b, gpt-oss-20b, llama-3.1-8b) and rotates the active model per iteration via os.environ["GROQ_MODEL_RAPIDO"], multiplying effective overnight throughput by ~5×.

Discussion

The most striking finding of the live LLM-driven run is the semantic coherence of the recovered communities (Table 2). The Buffett–Munger dyad emerges as a clique with edge density 1.0 from purely behavioural data—neither persona was hard-coded as the other's preferred dialogue partner. Likewise, the "aggressive strategy" cluster groups four canonical takeover artists (Trump, Ellison, Icahn, Murdoch) with two large-software CEOs (Benioff, Nadella). These structures recapitulate documented affinities in the public record without supervision; we read them as evidence that the persona archetype prompts (engine/arquetipos.py: REGRAS_ESPECIAIS) carry sufficient semantic signal to drive non-trivial graph structure.

The negative skill scores in Table 1 (predictive power vs naive last-state predictor) are not a defect of the model but of the experiment size: with only eight observed transitions and a single dominant state, the naive predictor is near-optimal by construction. Skill scores become informative once the trajectory visits multiple states with non-degenerate transition probabilities; that regime requires longer runs (we estimate ≥ 50 steps to trigger the auto-calibrator and ≥ 100 steps to surface Mules reliably). The benchmark was deliberately included in the release pipeline so future runs report this number automatically rather than rely on intuition about predictive value.

The earlier 56-step heuristic-only run remains the principal evidence for online calibration: perplexity 15.577 → 1.377 (91.2% reduction). This validation predates the LLM run and is independent of LLM availability. The transition matrix learned by Laplace MLE is exposed via /api/v1/vila/psicohistoria/calibrar; no recalibration is needed at query time because the matrix is updated every 50 steps online.

A practical observation from the live run is the brittleness of free-tier LLM provider quotas. Groq's per-day token allowances (500 000 for the 8B model, 100 000 for 70B-versatile, 500 000 for Llama-4-Scout) were each exhausted within a single afternoon of development; the circuit-breaker (Wave 64) and template fallback (built into engine/cognitivo/conversar.py) ensured the simulator continued to produce meaningful trajectories without LLM access. The /conversas/llm-only filter (Wave 76) operationalizes the resulting bimodal dialogue distribution: heuristic templates and LLM-rich conversations are cleanly separable downstream.

A limitation of the current release is scale: the target of 1M concurrent agents2 requires a distributed architecture (Ray actors plus self-hosted vLLM), for which only the skeleton is implemented (Wave 9). A second limitation is the small number of LLM-driven steps in the experiment reported here; longer runs (> 500 steps) or intervention protocols (adversarial topic injection via the trigger engine) are expected to surface Mules and exercise the calibration pipeline more thoroughly. Both limitations are tractable and represent natural next experiments.

Methods

Implementation. Vila INTEIA is implemented in Python 3.11 using FastAPI 0.100+, NumPy 1.24+, SciPy 1.11+, NetworkX 3.1+, and NashPy 0.0.38+. The frontend is zero-dependency vanilla JavaScript with custom Web Components. Docker Compose configures a two-service stack (Vila FastAPI + MCP stdio server). All 387+ test cases pass in a GitHub Actions matrix covering Python 3.11 and 3.12.

Event sourcing. Each step emits a JSON-lines record (data/events/vila_events.jsonl) containing type, step, timestamp, and payload. The file is append-only; no updates or deletions are permitted. Replay reconstructs deterministic traces. The audit trail enables post-hoc meta-analysis across multiple runs (Wave 35), comparing KL divergences, universal versus rare states, and convergence distributions.

Causal inference. Do-operator interventions on the Markov chain force the target row to identity, blocking natural flow. Counterfactuals propagate the chain forward from the alternative value and measure total-variation distance at a chosen horizon. Average treatment effects compare probabilities of outcomes under distinct interventions.

Benchmarking. Timings reported in Table 2 are medians of 100–10 000 iterations (depending on base latency), measured with time.perf_counter on commodity x86 hardware.

Availability. Source, tests, datasets, Docker artefacts and this article are available at github.com/igormorais123/vila-inteia. Pre-compiled articles (v1–v5, this Nature-style summary) are deposited in the author's local repository. Four historical datasets (Brazilian municipal election 2024, Apple Vision Pro launch, Americanas 2023 accounting crisis, Brazilian impeachment 2016, TikTok virality 2024) totalling 50 events are included under data/backtest/.
